# General

## Project investigations

For investigations related to a project, use the shared `project-investigations`
skill at `~/.agents/skills/project-investigations/SKILL.md`. Read it before
investigating and when resuming an investigation. ClickUp is the source of
truth: record the full investigation and all supporting files in the project's
Space wiki, verify the saved record, and include its links in the handoff. Local
files are temporary working copies.

# Project-specific

## openshell

### Upstream repositories

Never act on an upstream repository yourself: no issue or PR comments, no new
issues or PRs, no reviews, labels or reactions, and no pushes. In OpenShell the
upstream is the `NVIDIA` remote (github.com/NVIDIA/OpenShell); `mpereira` is my
fork. Draft the text in a local file and hand it to me to post. This holds even
when a skill or another agent's instructions say to post.
